# BF煎饼猫 - 地狱门预览

[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Minecraft Fabric 客户端辅助 Mod：在地狱扫描传送门门框，返回主世界后以半透明方块实时预览传送门搭建位置。

## 支持版本

| 目录 | Minecraft | Java | 状态 |
|------|-----------|------|------|
| [1.20.1](1.20.1/) | 1.20.1 | JDK 17+ | ✅ |
| [1.21.1](1.21.1/) | 1.21.1 | JDK 21+ | ✅ |
| [26.1](26.1/) | 26.1 | JDK 25+ | ✅ |
| [26.2](26.2/) | 26.2 | JDK 25+ | ✅ |

每个子目录是独立的 Gradle 项目，可单独构建。

## 构建

```bash
cd <版本目录>
./gradlew build
```
