# BF煎饼猫 - 地狱门预览 Mod v2.0.0 更新公告

## 🎉 重大更新：全面支持 Minecraft 26.1

---

## 📋 版本信息

- **Mod 名称**：BF煎饼猫（地狱门预览）
- **版本号**：v2.0.0
- **支持 Minecraft 版本**：26.1
- **Fabric Loader**：≥ 0.18.0
- **Fabric API**：0.144.3+26.1
- **Java 版本**：≥ 25

---

## ✨ 更新内容

### 🔧 核心升级
- **全面升级至 Minecraft 26.1**，告别 1.21.1，拥抱最新正式版！
- 底层渲染系统完全重写，适配 26.1 全新的渲染管线（RenderPipeline）

### 🎮 功能保持不变
- ✅ **P 键**：切换 HUD 显示（地狱坐标提示）
- ✅ **[ 键**：循环切换传送门朝向（北/南/东/西）
- ✅ **R 键**：开关主世界预览渲染
- ✅ 地狱内自动扫描门框并计算主世界对应坐标
- ✅ 主世界实时预览传送门搭建位置（半透明幽灵方块 + 轮廓线）
- ✅ 搭建完成后自动关闭预览
- ✅ 支持 ModMenu + Cloth Config 配置界面

---

## 🔧 技术适配说明

本次更新涉及大量底层 API 迁移，主要包括：

| 适配项 | 说明 |
|--------|------|
| **资源定位符** | `ResourceLocation` → `Identifier`（Mojang 映射变更） |
| **消息系统** | `displayClientMessage` → `gui.setOverlayMessage` |
| **配置界面** | `AutoConfig` → `AutoConfigClient`（Cloth Config 26.1 适配） |
| **HUD 渲染** | `HudRenderCallback` → `HudElementRegistry`（包路径变更） |
| **世界渲染** | `WorldRenderEvents` → `LevelRenderEvents`（全新事件系统） |
| **渲染管线** | 旧版 `BufferUploader` + `RenderSystem` → 新版 `MultiBufferSource` + `VertexConsumer` |
| **相机 API** | `camera.getPosition()` → `camera.position()` |

## 📥 安装说明

### 环境要求
- **Minecraft**：26.1（正式版）
- **Java**：JDK 25 或 JDK 26
- **Fabric Loader**：0.18.6+（推荐）

### 依赖 Mod
| Mod | 版本 | 说明 |
|-----|------|------|
| Fabric API | 0.144.3+26.1 | 必需 |
| Cloth Config | 26.1.154 | 配置界面必需 |
| ModMenu | 18.0.0-alpha.8 | 可选（推荐安装，可在模组菜单中配置） |

### 安装步骤
1. 确保已安装 Fabric Loader 0.18.6+
2. 将 `portal-preview-2.0.0.jar` 放入 `.minecraft/mods/` 文件夹
3. 安装 Fabric API 0.144.3+26.1
4. 安装 Cloth Config 26.1.154（配置界面必需）
5. （可选）安装 ModMenu 18.0.0-alpha.8
6. 启动游戏，享受地狱门预览功能！

## 🎮 使用指南

### 按键绑定
| 按键                | 功能 | 使用场景 |
|---------------------|------|----------|
| **P**               | 开启/关闭 HUD 显示 | 在地狱中使用 |
| **[**（左方括号）   | 切换传送门朝向 | 地狱或主世界 |
| **R**               | 开启/关闭预览渲染 | 主世界中查看搭建位置 |
| **K**（默认未绑定） | 打开配置界面 | 任意场景 |

### 使用流程
1. **进入地狱**，靠近地狱门框
2. 按 **P 键** 扫描门框，HUD 会显示地狱坐标和对应的主世界坐标
3. **返回主世界**，按 **R 键** 开启预览渲染
4. 根据幽灵方块提示搭建传送门
5. 全部 6 个内部方块搭建完成后，预览自动关闭
